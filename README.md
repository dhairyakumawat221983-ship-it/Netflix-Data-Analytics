# 🎬 Netflix Data Analytics Dashboard

> An end-to-end data analytics project focused on cleaning, analyzing, and visualizing Netflix movies and TV shows using Python and Power BI.

## 📌 Project Overview

This project explores the Netflix Titles dataset to identify patterns and trends across movies and TV shows.

The complete workflow covers **data cleaning → data transformation → exploratory analysis → visualization → interactive dashboard development**.

The final analysis is presented through an interactive **Power BI dashboard** designed to make key insights easy to explore.

---

## 🎯 Project Objectives

* Clean and prepare raw Netflix data for analysis
* Handle missing and inconsistent data
* Perform exploratory data analysis
* Analyze Netflix content by type, year, country, rating, and genre
* Create meaningful data visualizations
* Build an interactive Power BI dashboard
* Present analytical findings in a clear and understandable format
